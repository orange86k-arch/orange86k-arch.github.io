싱글리니지 원클릭

1.63 · 설치 파일 2026-11-06 18:35 판
설치 파일 받기 (zip)

윈도우 PC에서 받으세요. 압축을 풀면 싱글리니지_원클릭 폴더에 파일 두 개(bat, ps1)가 나옵니다. 둘이 같은 폴더에 있어야 합니다.

처음 하는 PC에서

  1. 받은 zip을 오른쪽 클릭 → [압축 풀기]로 풀고, 폴더 안 싱글리니지_원클릭.bat을 두 번 누릅니다. "PC 보호" 창이 뜨면 [추가 정보] → [실행]. 검은 창이 같이 뜨는데 다 끝날 때까지 닫지 마세요.
  2. 관리자 확인 창에서 [예]를 한 번 누릅니다 (Tailscale 설치).
  3. 브라우저가 열리면 Tailscale에 로그인합니다. 호스트가 보낸 공유 링크를 수락한 계정이어야 합니다.
  4. 게임을 받고 압축을 풉니다 (약 3.2GB, 집 인터넷 속도에 따라 몇 분). 끝나면 게임이 켜집니다.
  5. 아이디·비밀번호는 쓰던 그대로입니다. 처음이면 그냥 치면 계정이 만들어집니다.

다음부터, 그리고 다 놀고 나면

  • 같은 PC에서는 바탕 화면 싱글리니지 접속을 누르면 바로 켜집니다.
  • 게임을 끄면 Tailscale이 저절로 로그아웃됩니다.
  • 바탕 화면 싱글리니지 지우기를 누르면 게임 파일, 아이콘, 이 파일이 깐 Tailscale, 다운로드 폴더의 설치 파일까지 지워집니다. 캐릭터는 집 서버에 남습니다.

막힐 때

  • 백신(안랩 등)이 막으면 그 창의 [상세 보기]에서 허용·예외를 누르거나, 게임 받는 동안만 실시간 검사를 잠깐 끄세요. 설치 스크립트(PowerShell)나 게임을 서버에 연결하는 파일(wsock32.dll)을 악성으로 오인하는 경우가 있습니다. 실행되는 내용은 oneclick.ps1을 메모장으로 열면 그대로 보입니다.
  • "집 서버에 연결되지 않습니다": Tailscale 로그인이 끝났는지, 호스트 PC와 서버가 켜져 있는지 확인하세요.
  • 받다 끊기면 설치 파일을 다시 누르세요. 받던 곳부터 이어서 받습니다.
  • PC방처럼 프로그램 설치가 막힌 PC: 그대로 두면 됩니다. Tailscale 설치가 안 되면 설치 없는 접속기로 저절로 바뀝니다. 브라우저 로그인만 한 번 하세요.
